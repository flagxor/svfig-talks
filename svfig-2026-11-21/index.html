Stack Algebra

November 21, 2026 Forth Day!

Brad Nelson / @flagxor

Motivation

  • Inspired by Back and Forth - Hans Bezemer (thanks Martin Andronikos!)
  • Locals don't fit Forth
  • Shallow stacks are best
  • But we should be able to reason about stacks better
  • Are we missing an "algebra" of stack manipulation?

How to Build an Algebra

  • Find a set of "atomic" objects
  • Propose a set of rules describing how they can be manipulated while maintaining equivalence
  • Rules might require arithmetic for non-trivial algebras
  • Key Open Question: Can a small set of substitution rules connect all equivalent Forth expressions?

         SWAPk SWAPn ↔ SWAPn SWAPk SWAPn SWAPk if |k-n| = 1

Rule M1: Overhead Passing -- DUPk SWAPn ↔ SWAPn DUPk if k≥n+2
Rule M2: Underneath Dipping -- SWAPk DUPn ↔ DUPn SWAPk+1 if k>n
Rule M3: Useless Duping -- DUPn SWAPn ↔ DUPn
Rule M4: Left Capping -- DUPn SWAPn+1 ↔ SWAPn DUPn+1 SWAPn
